OPTIONAL QUATERNIUS ENVIRONMENT MODELS

Place modular .glb/.gltf/.fbx files in this folder or any subfolder. The loader
searches filenames for these keywords and uses the first alphabetical match:
  wall / bulkhead  -> wall modules
  floor / deck     -> floor modules, tiled across large floor areas
  door / hatch     -> airlock blast-door visual
  console / terminal / computer -> sabotage console visual
  crate / container / box -> cargo crate visuals
  pod / capsule / escape -> optional escape-pod model

Recommended: rename one selected module of each category to simple names such as
wall.glb, floor.glb, door.glb, console.glb, crate.glb, and pod.glb. The loader
keeps collision shapes generated by the game, so the external mesh is visual-only.
Keep all GLTF .bin and texture sidecars in their original relative folders.

No external assets are required; procedural PBR/primitive fallbacks are supplied.
